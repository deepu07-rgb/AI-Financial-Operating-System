## Scope delivered

- Independent `aifos-document-store` Rust package.
- Native multi-file picker contained behind one custom Tauri command; the
  frontend receives outcomes but never source paths.
- Streaming SHA-256 and managed copy with a 250 MiB per-file ceiling.
- PDF, PNG, JPG, and JPEG extension plus signature validation without parsing.
- Empty, unsupported, spoofed, changing, symbolic-link, directory, internal-store,
  and oversized source rejection.
- UUID/hash-derived relative managed paths, staging cleanup, file flush, atomic
  rename, canonical containment checks, and database-failure cleanup.
- Exact duplicate detection with reject, link, and keep decisions.
- Batch cap of 100 and independent per-file error results.
- Document byte size/media type persistence and immutable audit evidence.
- Schema migration 2 plus an automated schema-1-to-schema-2 upgrade test.
- ADR-0004 and updated architecture, threat, dependency, SBOM, and notice records.
