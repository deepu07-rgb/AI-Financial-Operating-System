- Date: 2026-08-04

## Scope delivered

- A dedicated Rust backup package creates a consistent SQLite online snapshot,
  collects the exact managed document set and bounded configuration, and emits
  complete per-table JSON and CSV exports with format documentation.
- A versioned manifest binds workspace identity, schema, table counts, file
  kinds, sizes, and SHA-256 digests. A deterministic TAR stream is encrypted
  with an age v1 scrypt passphrase recipient; the passphrase is not persisted.
- Backup creation stages beside the user-selected destination, flushes and fully
  verifies the encrypted artifact, refuses overwrite, then renames it. A failed
  attempt does not replace a previous successful archive.
- Verification works without restore and records its result and time. It checks
  authenticated decryption, exact contents, hashes, safe paths, resource limits,
  SQLite integrity/schema, document metadata, and portable table coverage.
- Restore validates into staging, refuses an existing workspace, applies known
  migrations, records `workspace.restored`, and installs the recovered database,
  managed documents, and eligible configuration into a clean workspace.
- Settings provide native create/verify/restore/export workflows, a configurable
  reminder interval, last successful destination, latest verification result,
  explicit passphrase-loss guidance, and a plaintext export warning.
- Backup start/completion/failure, verification, portable export, and restore
  operations emit audit evidence when associated with a workspace.

## Security and resilience coverage

- Wrong passphrases and modified ciphertext fail authenticated decryption.
- Archive extraction rejects absolute paths, parent traversal, links, duplicate
  or unexpected entries, entry-count/size excess, and payload/manifest mismatch.
- Managed documents are canonically contained and must match database size/hash
  metadata. Portable table metadata must exactly match the snapshot.
- Restore never overwrites an installed workspace. Temporary staging directories
  are removed on success or failure.
- CSV text is quoted, UTF-8 BOM encoded, and neutralizes spreadsheet formula
  prefixes. JSON retains typed values and represents blobs as hexadecimal data.

## Explicit boundaries

- Active workspace databases and managed documents remain plaintext on disk.
  WP-08 encrypts backup archives, not the installed workspace. OS keychain
  integration, workspace encryption, and auto-lock are not claimed.
- Portable JSON/CSV export is intentionally plaintext and prominently labeled
  sensitive.
- FR-BKP-004 incremental backup is a Should requirement and remains deferred.
  Atomic verified full backups ensure a failed new attempt does not corrupt a
  prior archive.
- Reminder configuration and due-state display are implemented, but no
  background scheduler or notification service is claimed.
- Completed audit evidence is written after the archive snapshot is finalized,
  so a given archive includes its `backup.started` event; its corresponding
  `backup.completed` event is retained in the live workspace and later backups.
- The user-held archive passphrase cannot be recovered by AIFOS.
