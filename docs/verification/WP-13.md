## Safety and privacy invariants

- No API key, LLM model, provider SDK, support endpoint, telemetry client, raw
  diagnostic log, or customer-content upload was added.
- Support preview and export bytes cannot diverge without a hash/token mismatch.
- Workspace identifiers, names, users, filenames, paths, OCR text, finance
  values, audit details, and document bytes are excluded from the bundle.
- Pilot metrics read append-only local evidence and expose aggregates only.
- Existing files are not overwritten; audit failure removes the new bundle.
