## Scope delivered

- Versioned provider-neutral request/response TypeScript contracts and canonical
  JSON Schemas. The request contains a recent consent receipt and typed selected
  records but cannot choose a provider or model.
- Strict Ed25519 bearer-token verification for algorithm/type/version, canonical
  encoding, signature, exact claims, issuer, audience, one-hour maximum lifetime,
  clock skew, tenant, and role.
- Tenant policy controls activation, supported analysis tasks, simple modes,
  provider routing, context limits, daily requests, per-request cost, daily cost,
  and mandatory no-retention policy.
- A provider registry and adapter interface with no live implementation. Invalid
  response schema/citations receive one bounded retry, then a safe visible error.
- Citation source IDs must exist in the selected request records. Narrative,
  assumptions, missing data, actions, confidence, and the exact advice disclosure
  are required and bounded.
- Atomic request-ID reservation prevents duplicate billing. Integer micro-USD
  metadata is recorded separately from finance payloads and aggregates retries.
- Authentication failures, rejected analyses, and completions have a separate
  structured security-audit sink containing safe identifiers/outcome codes only.
- A bounded HTTP adapter enforces JSON, body/header/request limits, no-store
  responses, safe error text, and TLS/trusted-proxy policy.
- The desktop Advisor route accurately reports that the gateway contract is
  ready while provider, credentials, network access, and data transmission remain
  disabled.
