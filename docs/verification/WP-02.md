## Scope delivered

- Rust workspace with independent `aifos-domain` and `aifos-storage` packages.
- UUID entity IDs, strict currency codes, checked integer money, bounded fixed
  decimals, validated ISO dates, and Unix-millisecond UTC timestamps.
- Core operational entities for workspace, local user, party, immutable document
  metadata, versioned invoice drafts/lines, review events, and audit events.
- Bundled SQLite 3.53.2 through `rusqlite` 0.40.1.
- One database per company, native UUID-derived paths, foreign keys, WAL,
  full-synchronous durability, busy timeout, and untrusted schema mode.
- Ordered, checksummed, append-only migration ledger and initial strict schema.
- Typed repositories with immediate transactions and atomic audit events.
- Database triggers protecting documents, invoice snapshots/lines, review events,
  audit events, and migration history from update/delete.
- Narrow Tauri commands to create or open a workspace without accepting arbitrary
  filesystem paths. No onboarding UI is enabled yet.
- ADR-0003 and updated architecture, threat, dependency, SBOM, and notice records.

## Risk and follow-up

- Workspace databases are local but plaintext. Encryption, credentials,
  auto-lock, backup/restore, and recovery are not claimed by WP-02.
- The schema provides document metadata invariants only. Managed file copying,
  MIME validation, hashes calculated from bytes, duplicate decisions, and safe
  document paths belong to WP-03.
- Review events and versioned invoice snapshots are persistence primitives; the
  review state machine and correction UI belong to WP-05.
- Crash recovery and migration-from-every-released-version testing expand when a
  second schema version and packaging lifecycle exist.
