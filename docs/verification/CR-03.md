## Scope delivered

- Invoices is a real approved/staged/rejected register with search, filters,
  deterministic sort, obligation state, source/review handoff, audit count,
  categories, and optional PO/GRN references.
- Review approval conservatively creates an approved operational invoice. If
  materialization fails, the review case is automatically reopened so an
  approved document cannot silently disappear from the register.
- Parties is a versioned supplier/customer master. Corrections append a new
  version, duplicate merge records an immutable source-to-target link, and old
  records remain queryable. Reviewers cannot mutate finance masters.
- Invoice approval and settlement are separate. Approval creates an open
  obligation; only settlement/write-off/reversal evidence changes the exact
  minor-unit balance. Dispute state is an independent append-only event.
- Manual settlement capture and native CSV/Tally file import are implemented.
  Files remain behind a native picker and short-lived workspace-bound token.
  Commit reparses the file, verifies the preview hash, requires a named Owner or
  Finance operator, imports all valid rows atomically, isolates invalid rows,
  and skips repeated external IDs using a source fingerprint.
- Payments explicitly states that AIFOS is not connected to a bank and cannot
  execute a payment. Dated manual cash snapshots and scenario buckets expose
  freshness rather than implying a live balance.
- Vendor-bank references become trusted only after explicit typed confirmation.
  Native code normalizes and hashes the value and persists only its fingerprint
  and masked suffix; OCR bank text never creates a trusted master.
- Category bulk assignment requires a deterministic preview hash and a named
  reason. A domain-safe undo appends compensating metadata and preserves the
  original run and source evidence.
- The synthetic sample now includes an approved payable, category, PO, GRN,
  partial settlement, dated cash snapshot, and reserve bucket so every CR-03
  register can be explored immediately.
