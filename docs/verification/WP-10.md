## Scope delivered

- Frozen-report-only analysis scope with stored-contract SHA-256 verification.
- Five supported task types: profit movement, payment priorities, overdue
  exposure, supplier trends, and cash scenarios.
- Deterministic task-specific context capped at 250 records. Original documents,
  OCR/document text, paths, invoice/document/user/workspace identifiers, report
  notes/branding, and contact/tax/bank data are excluded. Counterparties are
  pseudonymized and unsupported free text is redacted.
- Preflight shows report period, categories, approximate record count, estimated
  context units/premium status, exclusions, bounded preview, and context hash.
- Explicit one-request consent. The native command rebuilds the context and
  rejects changed bytes before it records the receipt, minimized snapshot, and
  safe audit event.
- SQLite schema 7 and repositories for consented requests, optional immutable
  answers, list/export/delete, and safe audit integration. Deletion cascades the
  request context and answer while preserving only a payload-free audit event.
- Strict answer validation for schema version, required disclosure, confidence,
  execution/cost metadata, allowlisted source, exact field/value equality, and
  citation coverage for narrative numbers.
- Advisor answer UI for narrative, cited figures, assumptions, missing data,
  proposed actions, confidence, disclosure, “View supporting data,” JSON export,
  and deletion. Prepared items show provider unavailable and data sent: none.

## Explicit boundaries

- No API key, provider SDK, live provider, local LLM, model, model weight,
  tokenizer, vector database, or desktop HTTP capability is present.
- Recording consent does not send data. No synthetic answer is substituted.
- Provider-backed benchmark accuracy and provider regression cannot truthfully
  run until a provider is separately approved and configured server-side.
- The Advisor can save only a response matching a consented request and has no
  mutation interface for approved records, rules, frozen reports, payments,
  email, negotiation, filing, or connectors.
- Production tenant identity, persistent cloud policy/metering, provider
  retention/legal review, deployment, and external penetration testing remain
  release gates.
- Cargo continues to report the already documented upstream
  `proc-macro-error2` 2.0.1 future-compatibility warning from the WP-08 age
  dependency graph; current Rust 1.85 tests and strict Clippy pass.
