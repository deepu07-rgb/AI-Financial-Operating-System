# AI Contracts

This package contains types only. It defines version 1 of the provider-neutral
cloud analysis request, structured answer, exact source-field/value citations,
disclosure, and integer
micro-unit cost metadata shared by the future desktop context builder and the
cloud gateway. WP-10 requires each citation value to equal the selected frozen
context field and requires narrative numbers to appear in citation claims.

The executable validators live in the gateway. Canonical JSON Schemas are in
`schemas/api/cloud-analysis-request-v1.json` and
`schemas/api/cloud-analysis-response-v1.json`.
